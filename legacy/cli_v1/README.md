# Ensina Logica

## Descrição

Ensina Logica é um protótipo educacional desenvolvido em Python com o objetivo de ajudar alunos iniciantes a visualizar o funcionamento das estruturas básicas da programação.

O sistema apresenta exemplos simples de estruturas de controle e explica passo a passo como o algoritmo é executado.

Este projeto nasceu da observação de dificuldades comuns no ensino de lógica de programação em ambientes educacionais.

## Funcionalidades da versão 1

- Menu interativo em terminal
- Demonstração de estruturas condicionais (`if`)
- Demonstração de estruturas condicionais (`if/else`)
- Demonstração de laços de repetição (`for`)
- Demonstração de laços de repetição (`while`)
- Explicação passo a passo da execução

## Tecnologias utilizadas

- Python
- PyCharm

## Objetivo

Criar um ambiente simples que torne o raciocínio algorítmico mais visível para alunos iniciantes.
